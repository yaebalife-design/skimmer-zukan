「必要か」の答えは当サイトでは出せません
かわりに、メーカーがろ過構成をどう想定しているかを読みます

要点 2026.09.06 確認
  • 必要かどうかは当サイトでは判断しません。水質や生体への影響を書かない方針のため、「入れれば水が良くなる」「なくても大丈夫」のどちらも書きません。
  • かわりに読めるのが、メーカーが対応水量をろ過構成で分けているという事実です。現行84機種のうち48機種が2つ以上の値を公表しており、その多くが「他のろ過と併用する場合」と「本品のみの場合」の区別です。
  • カミハタは両方の数値を示しています。海道達磨は他の生物ろ過と併用360L以下／本品のみ150L以下、海道河童は単体使用で小 約30L以下・大 約60L以下／生物ろ過と併用で小 約60L以下・大 約120L以下です。同じ本体でも、想定するろ過構成で公称値が2倍以上変わります。
  • 海外ブランドは「最大対応水量／ベルリン最大対応水量」という書き方が多く、OCTO 21機種とTUNZE DOC 2機種がこの形です。例：OCTO Classic 110S 最大500L／ベルリン160L、TUNZE 9410 最大1200L／ベルリン200L。
  • つまりメーカーは、他のろ過と組み合わせるか、スキマー中心の構成にするかで対応できる水量が変わるという前提で数値を出しています。どちらの構成にするかは飼育者の判断で、当サイトはその判断を代わりに行いません。
出典：カミハタ・LSS研究所（OCTO／TUNZE）ほか各メーカー・輸入代理店の製品ページ（当サイトのデータベース・確認 2026-09-06）。

「海水魚 プロテインスキマー 必要性」「いらない」「なし」で調べている方へ。当サイトは水質や生体への影響を書かないため、必要かどうかの結論は出しません。かわりに、メーカー自身が対応水量を「他のろ過と併用する場合」と「本品のみの場合」で分けて公表している事実と、その公表値を並べます。判断の材料としてお使いください。

当サイトが書くこと・書かないこと

書くことメーカーが公表している対応水量・寸法・水位・消費電力・交換部品と、その出典URLと確認日
書くこと泡で有機物を分離するという一般的な構造の説明（仕組みの記事）
書かないこと水質・生体・病気への影響、入れた場合と入れない場合の比較、必要性の結論

理由は、当サイトが確認できるのがメーカーの公表資料だけで、飼育結果を測っていないからです。測っていないことを書かない方針はこのサイトについてにまとめています。

「メリット・デメリット」「不要」で調べている方へ

海水魚水槽 プロテインスキマー 必要 のように調べている方に向けて、当サイトの立ち位置をはっきりさせておきます。メリットもデメリットも、当サイトは書きません。導入した場合としない場合を比べた測定を当サイトが行っていないためです。

書かないことメリット・デメリットの一覧、プロテインスキマー 不要／いらない の結論
書かないこと白点病などの病気、コケ、栄養塩、水換えの回数への影響
書けることメーカーが対応水量をろ過構成で分けている数値（下の一覧）、本体が水槽に収まるかの公表値

海水水槽 プロテインスキマー なし の構成でどうなるかも、同じ理由で書きません。判断の材料として使えるのは、メーカーが「他のろ過と併用する場合」と「本品のみの場合」で数値を分けている事実です。

海水水槽 立ち上げ の段階でどう運用するかについては、メーカー資料で確認できた指定がありませんでした（確認 2026-09-06）。運用の手順は各機種の取扱説明書をご確認ください。取扱説明書PDFのリンクは各機種の詳細ページの出典欄にあります。

メーカーは「併用」と「本品のみ」で数値を分けている

カミハタの2機種は、他の生物ろ過と組み合わせるかどうかで対応水量を2段階で示しています。本体は同じでも、想定するろ過構成で公称値が変わります。

海道達磨①他の生物ろ過と併用 360L以下／②ベルリン式など本品のみ 150L以下［出典：カミハタ公式］
海道河童フィルター 小単体使用 約30L以下／外部式・上部式などの生物ろ過と併用 約60L以下［出典：カミハタ公式］
海道河童フィルター 大単体使用 約60L以下／生物ろ過と併用 約120L以下［出典：カミハタ公式］
wavereef Nano Skimmer Standard 100〜100L（生物濾過併用時の参考値）［出典：LSS研究所］

海道河童はろ過カートリッジを内蔵しており、メーカーの表記でも「フィルター」の名前が付いています。スキマーとフィルターの構造の違いはフィルターとの違いの記事にまとめています。

海外ブランドの「最大／ベルリン式」という書き方

OCTO 21機種とTUNZE DOC 9410／9430は、対応水量を「最大対応水量」と「ベルリン最大対応水量」の2つで公表しています。ベルリン式はろ材による生物ろ過を主に使わない構成を指す一般的な呼び方で、そちらの数値は小さく設定されています。

OCTO Classic 110S最大対応水量500L／ベルリン最大対応水量160L［出典：LSS研究所］
OCTO Regal 200-S最大1500L／ベルリン400L［出典：同上］
OCTO Regal 250-S最大2400L／ベルリン800L［出典：同上］
TUNZE DOC Skimmer 9410 DC最大対応水量1200L／ベルリン最大対応水量200L［出典：同上］
TUNZE DOC Skimmer 9430 DC最大3500L／ベルリン400L［出典：同上］

この2つの数値の比は機種によって3倍から6倍の開きがあります。当サイトの表では大きい方を「対応水量（魚）」、小さい方を「対応水量（サンゴ）」の列に置き、メーカーの表現は「対応水量の但し書き」列にそのまま残しています。分け方の全パターンはサンゴ水槽と魚水槽の対応水量にまとめました。

自分の構成で読むときの手順

  1. ① 水槽の水量を計算する 外寸から計算します。60cm規格は満水で約64.8L、水位を3cm下げると約59.4Lです。オーバーフロー水槽ならサンプの水量も足します。規格ごとの計算値はトップの水量の目安にあります。
  2. ② 併用か本品のみかを決める 他のろ過器と組み合わせるのか、スキマー中心の構成にするのかで、見るべき公称値が変わります。メーカーが2つの値を出している機種は、その区別を明示しています。
  3. ③ 公称値が①を上回る機種に絞る 当サイトの絞り込みは「公称対応水量 ≧ 計算水量」で機種を出します。トップの絞り込みで水槽サイズを押してください。
  4. ④ 本体が収まるかを確認する 数値が足りていても、外形・必要水深・水槽の縁の厚さが合わないと設置できません。各機種の詳細ページに公表値と出典を載せています。

よくある質問

海水魚水槽にプロテインスキマーは必要ですか？

当サイトでは判断しません。水質や生体への影響を書かない方針のためです。判断の材料として、メーカーが対応水量を「他のろ過と併用する場合」と「本品のみの場合」で分けて公表している数値を掲載しています。

プロテインスキマーなしでも飼育できますか？

その問いに当サイトは答えを出しません。事実として言えるのは、カミハタが海道達磨で「他の生物ろ過と併用360L以下／本品のみ150L以下」と、ろ過構成によって対応水量を分けて公表していることです（確認 2026-09-06）。

「ベルリン式」とは何ですか？

ろ材による生物ろ過を主に使わない水槽の構成を指す一般的な呼び方です。OCTO 21機種とTUNZE DOC 2機種は、この構成での対応水量を「ベルリン最大対応水量」として別に公表しています。

立ち上げの段階から使うものですか？

立ち上げ時期の運用について、メーカー資料で確認できた指定はありません。当サイトが掲載しているのは仕様の公表値で、運用の手順は各機種の取扱説明書をご確認ください。
